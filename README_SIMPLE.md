# CC保镖

CC保镖是一款面向 Claude 与 Codex 的鸿蒙代理客户端。CC 取自 Claude 和 Codex，寓意守护它们的网络连接。

从 [Releases](https://github.com/sssstwee/xiaomao-ai-proxy/releases) 下载 HAP；未签名的 HAP 需用包含目标手机 UDID 的鸿蒙调试证书和 profile 签名，再通过 DevEco Studio 安装到已开启开发者模式和 USB 调试的鸿蒙手机。

首次打开时粘贴 VPS 提供的 HTTPS 订阅地址，保存后直接进入连接首页，无需用户名和密码。订阅链接仅保存在手机安全存储中，公开安装包不包含私人链接。后续线路、版本和首页显示均从 VPS 获取；网络暂时不可达时可复用已校验的本地配置。
